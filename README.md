# Cryptmaster - Whisper (planned)

A future, separate BepInEx mod that lets Cryptmaster's voice input use the Whisper speech recognition
that ships with the game but was never used, as an alternative to Windows Speech Recognition (which stays
the default; the choice will be a toggle in the Options menu).

Nothing is built yet. `textos\` holds draft texts the mod will inject, in every language it supports
(ENG, SPA, and POR for when the Portuguese localisation is installed).

Wording rule: the Whisper mode is presented as an alternative and an attempt to implement an unused original
feature; it never promises better performance than Windows Speech Recognition.
